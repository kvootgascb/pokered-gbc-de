# Spezialhändler auf der M.S. Anne

In Erweitert erscheint nach dem ersten Top-Vier-Sieg ein Händler auf dem Deck,
unter denselben Bedingungen wie die beiden Attacken-Helfer. Er ist bei den
wiederkehrenden Schiffsbesuchen erreichbar. Beim natürlichen Betreten werden
die drei zusätzlichen Gäste in Classic oder vor dem Champion-Sieg ausgeblendet.

Der Händler bringt seltene Vorräte von seinen Reisen mit. Sein Angebot:

| Item | Preis |
| --- | ---: |
| AP-Plus | 20000 |
| Top-Äther | 3000 |
| Elixier | 5000 |
| Top-Elixier | 10000 |
| Mondstein | 5000 |
| Top-Beleber | 10000 |

Der Vorrat ist unbegrenzt. Pro bestätigtem Kauf wird ein Exemplar hinzugefügt;
danach bleibt die Auswahl für weitere Käufe erhalten. B oder ZURÜCK beendet
das Angebot. Der aktuelle Geldbetrag ist im Kaufmenü sichtbar.

Ohne Geld oder Platz wird nichts abgezogen. Bestehende Stapel und volle Beutel
verwenden die normalen Inventarregeln. Die Preise gelten nur bei diesem Händler;
die ursprünglichen Kauf-/Verkaufspreise und die Gen-1-Itemwirkungen bleiben gleich.
Es gibt keine zusätzlichen Kaufzähler oder Änderungen am Saveformat.

Die Emulator-Tests prüfen alle Preise, exakte Zahlung, fehlendes Geld,
wiederholte Käufe, volle Beutel und Stapel, beide Freischaltbedingungen und
echte NPC-Käufe samt Bestätigung auf dem Deck, einschließlich Top-Beleber.
Die Menüs werden mit ausgeblendeten Karten-Sprites und korrekter Rückkehr
zur Karte geprüft. Die Dienstdialog-Tests
markieren die ursprünglichen Decktrainer als bereits besiegt, damit dort keine
unabhängigen ersten Trainerkämpfe die Prüfung unterbrechen.
